# AnyDoc 原生版（Windows）

> 把 Word / PowerPoint / Excel / PDF / EPUB 等文档转成干净的 Markdown
>
> **解析内核：[firecrawl/anydoc](https://github.com/firecrawl/anydoc) v0.2.4（MIT）**
>
> **原生 Windows 窗口** —— 无浏览器、无 WebView2、零运行时依赖。

---

## 快速开始

1. 解压整个文件夹
2. 双击 `AnyDoc.exe`
3. 拖入文档 → 选输出目录 → 点「开始转换」

进度直接显示在窗口里，不用切到任何网页。

### 状态徽章

| 状态 | 显示 | 含义 |
|------|------|------|
| 等待 | 灰点 `等待` | 排队中 |
| 转换中 | 靛蓝脉冲点 `转换中` | 正在处理 |
| 成功 | 绿 `✓ 12ms` | 完成，带耗时 |
| 失败 | 红 `✗ 需 OCR` | **直接给原因** |

失败时显示具体原因（需 OCR / 文件已加密 / 文件结构损坏 / 超出安全限制），
不是笼统的「转换失败」。

### 输出目录

- **默认**：与源文件同目录
- **可改**：点「输出目录」按钮选择其他位置
- 选择文件夹批量转换时，**子目录结构会保留**（`2026/Q1/a.docx` → `2026/Q1/a.md`）

## 支持的格式（14 种）

| 类别 | 扩展名 |
|------|--------|
| Word | `.doc` `.docx` `.docm` |
| PowerPoint | `.ppt` `.pptx` `.pptm` |
| Excel | `.xls` `.xlsx` `.xlsm` `.xlsb` |
| OpenDocument | `.odt` `.ods` `.odp` |
| 其他 | `.rtf` `.epub` `.csv` `.pdf` |

### 格式识别看内容，不只看后缀

anydoc 读**文件字节签名**判断真实格式（PDF header、RTF 起始标记、OLE 流名、ZIP 内部 mimetype）。

把 `报告.docx` 改名成 `报告.pdf`，**它照样能正确解析**。

## 已知边界

| 情况 | 行为 |
|------|------|
| 扫描件 / 图片版 PDF | ❌ 不支持，需要 OCR —— 官方 anydoc 内核本地就不含 OCR，本版**完全本地运行，不联网** |
| 加密 / 有密码的文档 | ❌ 报错 `文件已加密` |
| 结构损坏的文件 | ❌ 报错 `文件结构损坏`，不会返回半成品 |
| 超出安全限制 | ❌ 报错 `超出安全限制` |
| Excel 公式 | 读取计算结果，不保留公式本身 |

## 排障：窗口最大化后黑屏

v0.5.2 / v0.5.3 在部分电脑上最大化会整屏黑屏，**v0.5.4 已修**
（客户区计算统一用 `WINDOWPOS`；位图创建失败时退化为直接绘制，不会再「什么都不画」）。

万一还有问题，程序会在**同目录**（或 `%TEMP%`）写一个 `anydoc-diag.log`，
里面记着缩放比例、窗口矩形、客户区矩形、工作区、崩溃信息。把这个文件发过来即可定位。

## 系统要求

- **Windows 10 / 11**（64 位）
- **无需安装任何运行时**（不需要 Python / Node / WebView2）
- 单文件约 6.7MB

---

## 技术说明

- **原生 Win32 GUI**（windows-rs 0.58），非 WebView 封装
- **后台线程池**转换，CPU 核数 − 1（上限 4），界面全程不卡
- 列表用 `ListBox + LBS_OWNERDRAWFIXED` 自绘，状态徽章为圆角药丸
- 文件图标取自 Windows 系统（`SHGetFileInfo`）
- 文件夹选择器用 `IFileDialog`（Win11 现代风格）
- 跟随系统深色模式（读 `AppsUseLightTheme` 注册表）
