# AnyDoc 原生版（Windows）

> 把 Word / PowerPoint / Excel / PDF / EPUB 等文档转成干净的 Markdown
>
> **解析内核：[firecrawl/anydoc](https://github.com/firecrawl/anydoc) v0.2.4（MIT）**
>
> **原生 Windows 窗口** —— 无浏览器、无 WebView2、零运行时依赖。

---

## 快速开始

1. 解压整个文件夹
2. 双击 `AnyDoc.exe`
3. 拖入文档 → 选输出目录 → 点「开始转换」

进度直接显示在窗口里，不用切到任何网页。

界面按设计稿 1:1 还原：`grid-cols-12 gap-4` 的表格栅格、行内独立进度条、
拖放区空状态、底部输出目录 + 状态栏，全部原生绘制。

### 状态显示

| 状态 | 显示 | 含义 |
|------|------|------|
| 等待 | 灰 `排队等待中` | 排队中 |
| 转换中 | 蓝 `解析转换` + 行内进度条 | 正在处理，**每个文件独立进度** |
| 成功 | 绿 `✓ 转换完成 (1.2s)` | 完成，带耗时 |
| 失败 | 红 `需 OCR` / `文件结构损坏` | **直接给原因** |

进度分三段：读取（真实字节 0→30%）、解析（30→95%，官方内核一次性调用，
无法细分，用不确定态动画表示仍在进行）、写入（95→100%，真实字节）。
**不伪造百分比。**

失败时显示具体原因（需 OCR / 文件已加密 / 文件结构损坏 / 超出安全限制），
不是笼统的「转换失败」。

### 输出目录

- **默认**：与源文件同目录
- **可改**：点「输出目录」按钮选择其他位置
- 选择文件夹批量转换时，**子目录结构会保留**（`2026/Q1/a.docx` → `2026/Q1/a.md`）

## 支持的格式（14 种）

| 类别 | 扩展名 |
|------|--------|
| Word | `.doc` `.docx` `.docm` |
| PowerPoint | `.ppt` `.pptx` `.pptm` |
| Excel | `.xls` `.xlsx` `.xlsm` `.xlsb` |
| OpenDocument | `.odt` `.ods` `.odp` |
| 其他 | `.rtf` `.epub` `.csv` `.pdf` |

### 格式识别看内容，不只看后缀

anydoc 读**文件字节签名**判断真实格式（PDF header、RTF 起始标记、OLE 流名、ZIP 内部 mimetype）。

把 `报告.docx` 改名成 `报告.pdf`，**它照样能正确解析**。

## 已知边界

| 情况 | 行为 |
|------|------|
| 扫描件 / 图片版 PDF | ❌ 不支持，需要 OCR（anydoc 本身不含 OCR） |
| 加密 / 有密码的文档 | ❌ 报错 `文件已加密` |
| 结构损坏的文件 | ❌ 报错 `文件结构损坏`，不会返回半成品 |
| 超出安全限制 | ❌ 报错 `超出安全限制` |
| Excel 公式 | 读取计算结果，不保留公式本身 |

## 技术说明

- **原生 Win32 GUI**（windows-rs 0.58），非 WebView 封装
- **全自绘**：标题栏、按钮、表格、进度条、滚动条都是自己画的，
  没有原生 `BUTTON` / `ListBox` 控件，位置和设计稿逐像素对齐
- **无边框窗口**：`WM_NCCALCSIZE` 把客户区铺满整个窗口（消掉顶部那条
  系统边框），再自己实现 `WM_NCHITTEST` 保留边缘缩放
- **后台线程池**转换，CPU 核数 − 1（上限 4），界面全程不卡
- 文件图标取自 Windows 系统（`SHGetFileInfo`）
- 文件夹选择器用 `IFileDialog`（Win11 现代风格）
- 跟随系统深色模式（读 `AppsUseLightTheme` 注册表）
- 字体回退：优先 `Microsoft YaHei UI`，系统没有时自动退到其它中文字体，
  不会把中文显示成方块；等宽字体同理
- 图标（加号 / 文件夹 / 垃圾桶 / 对勾 / 叉号 / 闪电 / 云朵）全部用 GDI
  画，不依赖字体里的特殊字符

## ⚠️ 首次运行出现「Windows 已保护你的电脑」？

这是 **Microsoft Defender SmartScreen** 的信誉拦截，不是病毒。

### 原因

从网上下载的文件会带一个 `Zone.Identifier` 标记（记录「来自互联网」）。
SmartScreen 看到「未知发布者 + 来自网络」就会拦截。

本程序用的是**自签名证书**（SHA256 签名有效），但自签名证书不在 Windows 的
受信任列表里，所以发布者身份无法验证 —— 加上刚发布、下载量不足，没有信誉分，
SmartScreen 就会拦。

### 解决（免费，立刻生效）

**方式 A：双击 `首次运行.bat`（推荐）**

它会自动：
1. 解除所有文件的网络标记
2. 如果你是管理员，顺手加进 Defender 排除项
3. 启动 AnyDoc

**方式 B：手动解除锁定**

1. 右键 `AnyDoc-v0.5.0-win-x64-portable.zip` → **属性**
2. 底部勾选 **「解除锁定」** → 确定
3. **重新解压**（在解除锁定之前解压出来的 exe 仍带标记）
4. 双击 `AnyDoc.exe`

**方式 C：直接对 exe 操作**

解压后右键 `AnyDoc.exe` → 属性 → 勾选「解除锁定」→ 确定 → 再双击运行。

**方式 D：加入 Defender 排除项**

右键 `解除安全警告-需管理员.bat` → **以管理员身份运行**。

### 彻底消除（需要付费证书）

上面的方法都是「绕过」，Windows 每次更新信誉库后可能再次拦截。

要**永久消除**，需要购买受信任的代码签名证书：

| 类型 | 价格 | 效果 |
|---|---|---|
| **EV**（扩展验证） | 约 ¥1500-3000 / 年 | **签名后立即不弹**，微软对 EV 证书给予即时信誉 |
| **OV**（组织验证） | 约 ¥800-2000 / 年 | 签名后仍可能弹，需积累下载量获得信誉 |

购买后用 `signtool sign /fd SHA256 /tr ... /td SHA256` 重签即可。
