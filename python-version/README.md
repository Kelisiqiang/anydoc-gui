# AnyDoc 本地转换器

把 Word、PPT、Excel、PDF、OpenDocument、RTF、EPUB、CSV 等文档一键转换成 **Markdown** 的本地小工具，基于 Firecrawl 官方开源的 [anydoc](https://github.com/firecrawl/anydoc) 引擎（Rust 内核，速度极快）。

**特点**

- 双击即用，全程不需要碰命令行
- 文件默认在本机转换，不出电脑
- 批量拖拽、逐个预览、单个/打包下载
- 干净的网页界面，打开浏览器即可操作

---

## 免安装版（推荐）

**`AnyDocConverter.exe`** 是打包好的独立桌面程序（自带软件窗口，不借助浏览器）：

- 任何 Windows 电脑双击即可用，**不需要安装 Python、不需要配置任何环境**
- 双击后直接弹出「AnyDoc 本地转换器」程序窗口，把文档拖进去即可转换
- 转换完成可预览 / 下载 / 打包下载；点「退出程序」或直接关窗即退出

> 提示：首次双击若提示"Windows 已保护你的电脑"，点「更多信息」→「仍要运行」即可
> （程序未签名，属正常提示）。

## 脚本版（源码运行）

1. 双击 **`start.vbs`**（无黑色窗口，推荐）
   - 或者双击 **`start.bat`**（带日志窗口，方便排查问题）
2. 首次运行会自动安装依赖（需联网，约 1–2 分钟），之后秒开
3. 浏览器自动打开工具页面，把文档拖进去即可转换

> 前提：电脑上装有 **Python 3.10 或更高版本**（没有的话先到 https://www.python.org/downloads/ 装一个，安装时勾选 "Add Python to PATH"）。

## 使用方法

1. 将文件拖入虚线区域，或点击选择文件，可一次拖入多个
2. 可选：勾选「联网 OCR」来识别扫描版/纯图片 PDF
3. 等待转换完成，每个文件会显示 排队中 → 转换中 → 完成/失败
4. 点「预览」查看 Markdown 渲染效果（可切换"源码"视图并复制）
5. 点「下载」保存单个文件，或「打包下载全部」一次性拿到 zip

## 扫描版 PDF 与在线 OCR

扫描/纯图片 PDF 没有文字层，本地引擎识别不了，需要在线 OCR。勾选「联网 OCR」后，转换顺序为：

1. **本地引擎**：能直接提取文字的文档（含文字层 PDF）本地搞定，不消耗云端额度
2. **MinerU**（若在「MinerU API Token」框填了 Token）：按行填入多个 Token 时，额度不足/解析失败会自动按顺序换下一个重试（在 [mineru.net](https://mineru.net) 官网申请）
3. **Firecrawl 官方**：兜底通道，不填 Key 也能用（额度较低），也可在「Firecrawl API Key」框填 Key 提高额度

> 隐私说明：开启联网 OCR 后，**只有扫描版/纯图片 PDF** 会发送到上述云端服务，其余文件始终在本机转换。

## 输出文件在哪里

转换成功的 `.md` 文件保存在本工具的 **`output` 文件夹**内，按转换时间分批存放。
点页面上的「打开输出文件夹」可一键定位。

## 常见问题

**扫描版 PDF 转换失败？**
有两类情况：

1. **文字层完整、夹带少量整版图片页**（如财新周刊：封面/广告是图片页，正文都是可复制文字）——旧版会误判为"扫描版"导致失败。新版已加**本地纯文本模式**：检测到这种情况直接用本地引擎提取文字层，**不联网、不花钱**，几秒出结果（内容完整，排版简化为纯文本，结果开头有说明）。
2. **真正的扫描版**（整本都是图片，无可复制文字）——本地识别不了，需勾选「联网 OCR」。勾选后：只有这类文件会发送到云端解析服务，其余文件仍在本机转换。

**勾选了「联网 OCR」还是失败？**
财新周刊这类高分辨率扫描 PDF 体积常在 8MB 以上，Firecrawl 匿名额度对其不稳定（实测 7.5MB 成功、11MB 失败）。请把「MinerU API Token」输入框填上你的 Token（在 [mineru.net](https://mineru.net) 注册即可免费领取，独立额度、单文件支持到 200MB），每行一个、可填多个自动轮询。界面会在拖入大文件 PDF 时给出黄色提示。

**双击没反应？**
先双击 `start.bat` 看日志窗口里的提示；最常见原因是 Python 未安装或首次安装依赖时网络不通。

**端口被占用？**
工具默认使用 8123 端口，被占用时会自动顺延到下一个可用端口，浏览器会打开正确的地址。

**单个文件有多大限制？**
单文件上限 500MB，超过会提示失败。

**文档里的图片呢？**
Markdown 是纯文本格式，无法内嵌图片字节。文档内嵌图片会以占位说明文字保留在 Markdown 中。如需完整图文提取，建议配合图片提取工具或使用 anydoc 的完整命令行能力（见下）。

**转换质量如何？**
anydoc 在 14 种格式的官方评测中均排名第一（Firecrawl 基准，满分 100 得分 81），支持标题、表格、公式（LaTeX）、列表、脚注等完整结构。

## 给爱折腾的人

本工具就是官方库的"壳"，底层能力全在。想直接用命令行：

```bash
# Node 版（npx 免安装）
npx @firecrawl/anydoc 报告.docx -o 报告.md

# Python 版
pip install firecrawl-anydoc
python -c "import anydoc; print(anydoc.to_markdown('报告.docx'))"
```

## 技术说明

- 后端：Python Flask，仅监听 `127.0.0.1`，不对外网开放
- 引擎：`firecrawl-anydoc`（MIT 协议，Firecrawl 开源）
- 目录结构：
  ```
  anydoc-gui/
  ├── start.vbs / start.bat   # 启动入口（双击）
  ├── install.bat             # 手动安装依赖
  ├── app.py                  # 后端服务
  ├── requirements.txt        # 依赖清单
  ├── static/                 # 网页界面
  ├── output/                 # 转换结果（自动生成）
  └── README.md               # 本说明
  ```

## 隐私说明

工具默认**纯本机运行**：文件由本地引擎解析，不上传任何内容。唯一例外是勾选「联网 OCR」且遇到扫描版 PDF 时，该文件会被发送到 Firecrawl 官方解析服务用于 OCR；如需更高的调用额度，可填入 Firecrawl API Key。
